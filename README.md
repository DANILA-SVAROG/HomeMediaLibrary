# Домашняя медиатека

Курсовая работа: каталог фильмов и сериалов на C# и WPF.

Для запуска нужна Windows и .NET 8 Desktop Runtime.
Для сборки нужен .NET SDK 8 или новее либо Visual Studio с компонентом «Разработка классических приложений .NET».

Откройте HomeMediaLibrary.sln и выберите HomeMediaLibrary запускаемым проектом.
Также можно запустить из папки проекта:

```text
dotnet run --project src/HomeMediaLibrary
```

Первый запуск открывает пустой каталог. Нажмите «Добавить», выберите фильм или сериал и заполните сведения.
Данные сохраняются в %LOCALAPPDATA%\HomeMediaLibrary\library.json, обложки — в соседней папке covers.
IMDb используется вручную: можно сохранить ссылку и открыть её в браузере. Интернет для каталога не нужен.
«Экспорт в JSON» сохраняет всю коллекцию, даже если включены фильтры. Обложки остаются отдельными файлами.
При переносе экспорта на другой компьютер нужно также перенести обложки и обновить пути к ним.

Проверка программы:

```text
dotnet test HomeMediaLibrary.sln
```
